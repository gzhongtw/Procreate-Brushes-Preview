# 審核說明

1. 在 macOS 安裝插件，匯入一個含內建筆觸的 `.brushset`。
2. 開啟預覽，確認名稱、順序及筆觸；點選卡片確認放大。
3. 以獨立 `.brush` 重複測試，並重新產生縮圖。
4. 以損壞檔測試，應顯示錯誤而不影響 Eagle。

無需帳號、API 金鑰、外部服務或 Procreate。隨包的 Universal Swift 元件僅解析本機筆刷並輸出縮圖；無下載、無網路、無系統設定變更。源碼與重建方式可提供審核。
