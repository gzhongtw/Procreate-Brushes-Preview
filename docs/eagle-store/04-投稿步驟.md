# Eagle 投稿步驟

資料核對：2026-11-19。這份資料包尚未上傳。

1. 在 Eagle 匯入資料包內「待匯入Eagle打包」本地專案。
2. 實測 `.brush`、`.brushset` 的預覽、空白鍵／雙擊、放大、縮圖。
3. 插件面板右鍵 →「打包插件」，取得 Eagle 正式匯出的 `.eagleplugin`。
4. 重新安裝匯出檔，再測一次主要流程。
5. Eagle 插件中心 →「投稿」→「投稿插件」→ 上傳 `.eagleplugin`。
6. 貼上 01 的文案、hello@zon.tw、02 的審核說明，放入圖示與封面，提交審核。

## 圖片
- 已備：1024 PNG 圖示、1800×1200 封面（圖片/封面-1800x1200.png）。
- 建議補 3 張實際畫面：縮圖／右側資訊欄、筆觸卡片、放大筆觸。
- 以最終投稿表單的尺寸限制為準，不套用其他平台規格。截圖須來自最終版本，避免私人路徑與未獲授權素材。

## 送審前剩餘項目
- Eagle 內建匯出及安裝驗收。
- 實際截圖（封面已備）。
- 確認隨包元件與圖示有散布權；本機元件未公證，需如實說明。
- 依 02 說明提供可合法供審核使用的筆刷樣本，或讓審核員使用自有筆刷；勿夾帶私人素材庫。
- 商店只宣告繁體中文與 macOS；不宣稱已支援 Windows。
