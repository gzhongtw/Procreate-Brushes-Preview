# Procreate Brushes Preview • macOS
預覽 Procreate .brush 與 .brushset 筆觸，支援 Finder 空白鍵預覽與縮圖。

- macOS 12 以上，支援 Apple silicon 與 Intel。
- 繁體中文。
- 快速鍵：⌘O 開啟、⌘W 關閉視窗、⌘M 最小化、⌘H 隱藏、⌘Q 結束、⌃⌘F 全螢幕。
- 第三方工具，非 Procreate 官方插件

安裝方式：解壓後將 Brushes Preview.app 移至「應用程式」。


# Procreate Brushes Preview • Eagle
在 Eagle 預覽 Procreate .brush 與 .brushset 的內建筆觸。

- 僅支援 macOS 12 以上、Eagle 4。
- 繁體中文。
- 支援筆刷縮圖與筆觸總覽。
- 第三方工具，非 Procreate 官方插件

安裝方式：雙擊或拖曳進 Eagle 安裝。

## 專案結構

- `outputs/Source`：Swift、共用介面與建置工具。
- `outputs/BrushPreview.eagleplugin-src`：最新 Eagle 外掛專案。
- `design`：核准的 Icon Composer 原檔。
- `docs/eagle-store`：上架文案、隱私與審核說明、圖片。
